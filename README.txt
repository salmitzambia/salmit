# Salmit Zambia Limited – Company Profile

## Run the project
1. Extract the ZIP file.
2. Keep `index.html`, `styles.css`, `script.js` and `sam12.jpg` in the same folder.
3. Open `index.html` in a modern web browser.

No installation or build tools are required.

## Customise the content
Edit the `sections` object in `script.js` to change the text shown when each menu item is clicked.
Replace `sam12.jpg` with another background image if required, keeping the same filename.

## Before publishing
The About Us, Vision, Mission and Core Values text is draft profile copy. Confirm it with the company.
The Clients section intentionally prompts you to add only approved client names/logos. Add verified contact details if you want them displayed.
